# Model Contract

For each stable subproblem ID record:

- decision target and requested output;
- candidate methods and rejection reasons;
- selected method and evidence IDs;
- symbols, units, equations, constraints, and assumptions;
- preprocessing and feature construction;
- algorithm steps, initialization, stopping rule, and complexity;
- upstream inputs and downstream outputs;
- baseline and validation requirements;
- known failure modes and fallback method.

Every equation must be implementable and every output must answer the statement.
