# Figure Contract

Each figure manifest record contains:

- stable `figure_id` and target paper section;
- one-sentence scientific claim;
- panel roles and subproblem IDs;
- source data and exact field locators;
- generation source and runtime;
- dimensions, language, color policy, and export files;
- uncertainty, sample-size, and statistical annotation definitions;
- caption evidence IDs;
- final-size visual review status.

Quantitative figures require reproducible code and data. Conceptual schematics require a verified label list and model-contract mapping. No figure may combine visual elements that imply unsupported causal or quantitative relationships.
